# Elias Cohen — personal website

Static portfolio for iameliascohen.com. No build step, no framework, no dependencies.
Open `index.html` in a browser (or `python3 -m http.server`) and it runs.

## Source of truth

The design lives in Claude Design, project `afb12fca-b83d-4207-ace6-725aef1819ea`,
files `Portfolio Redesign.dc.html` (English) and `Portfolio Redesign ES.dc.html`
(Spanish). The two share one structure; only copy differs. This repo is a 1:1
transcription: layout/styles from the EN file, copy from each file into its
`js/copy.<lang>.js`. When the design changes, re-read it and port the diff.
Do not restyle from memory.

## Layout

```
index.html        shell: head/meta/GA, nav, <main id="app">, footer
css/styles.css    every style, transcribed from the design's inline styles
js/data.js        CONFIG + FACTS + the empty COPY registry (no copy here)
js/copy.en.js     ALL English copy, registered as COPY.en (edit copy here, nothing else)
js/copy.es.js     ALL Spanish copy, COPY.es. Same shape as copy.en.js, key for key
js/copy.check.js  `node js/copy.check.js`: shape parity, study keys, placeholders
js/app.js         hash router, page templates, language picker, interaction layer
js/blobatar-hero.js  ES module: mounts the hero blobatar from CONFIG.blobatar (gaze + click bursts)
js/blobatar-favicon.js  ES module: draws the same blobatar on a canvas and animates the tab icon
vendor/blobatar/  blobatar 2.7.0 dist (internal.js, expression.js, motion.css). Verbatim; re-copy to upgrade
assets/           logos/<study key>.svg (from the design's logos/), favicon.svg (static blobatar) + favicon.png (192px raster), Elias-Cohen-Resume.pdf
.htaccess         Apache: old URLs → new hash routes, unknown paths → 302 to /
```

## Languages

Copy is a per-language object; templates read `L()` = `COPY[state.lang]`.
Strings carry `{placeholders}` filled from `vals()`; accented headlines are
`[before, word, after]` arrays. Number words and ordinals are per language.
Study `key`s (the hashes) and array shapes must match across languages;
`node js/copy.check.js` asserts that.

Which language loads, in order: a saved pick in `localStorage['ec-lang']`,
then the first entry of `navigator.languages` whose 2-letter prefix has a
copy file, else `CONFIG.defaultLang` (`en`). The nav picker (`.nav-lang`,
EN/ES buttons, `aria-pressed` on the active one) calls `setLang()`, which
saves the pick and re-renders the current route in place. `<html lang>`,
`<title>`, nav, badge and footer follow. The `<meta>` description and the
static `<title>` in `index.html` stay English (SEO fallback). Adding a
language = one more `copy.<xx>.js` registered on `COPY` and loaded in
`index.html`; the picker lists `Object.keys(COPY)`.

## Routes (hash-based)

| hash            | page          |
|-----------------|---------------|
| `/` or `#home`  | home          |
| `#about`        | about         |
| `#process`      | how I work    |
| `#resume`       | résumé (printable) |
| `#<study.key>`  | case study (`bettercloud`, `leadgenius`, `sender`, `selimex`, `la_fruteria`) |
| anything else   | 404 screen    |

"Work" in the nav is not a page; it scrolls to `[data-anchor="work"]` on home.

## What is dynamic

Nothing time-dependent is typed into copy. `FACTS` in `data.js` is the single source:

- `pmStart` (Jul 2020) → "Six years cutting the…", résumé "6+ years", About lede
- `careerStart` (Dec 2018) → "2018 → now" in the work header
- `studies.length` → "Five products", "The sixth one is still open."
- `stages.length` → "Five stages and a scoring model…"

`yearsSince()` floors whole years from month precision. Numbers render as words
via `numWord`/`ordinalWord` (0–15; falls back to digits beyond that).

Adding a case study = push one object to `studies` in every copy file. The home
grid, the "next" links, the counts, and the route all follow. Keep `key`
URL-safe (it is the hash) and identical across languages, and add its logo as
`assets/logos/<key>.svg` (card + case hero read it by key).

## CONFIG (data.js)

- `blobatar`: name, traits, palette, expression (string name from
  `blobatar/expression`), animate. Body/eyes are pinned to brand hex via
  `palette`. `animate: 'hover'` needs a fine pointer; motion.css goes static
  under `prefers-reduced-motion`.
  `gazeTravel` makes the eyes follow the cursor (gaze.js; fine pointer only).
  `burst`/`burstMs`: clicking the blobatar holds a random pose briefly.
- Favicon: `blobatar-favicon.js` removes the static `<link rel=icon>` tags and
  drives a 64px canvas PNG at 12 fps (breathe, bob, blink, glance, occasional
  pose). Static under reduced motion. Safari ignores dynamic favicons and shows
  `assets/favicon.svg` (also a blobatar, generated by the same geometry).
- `showMarquee`, `showMetrics`: toggle those home sections.
- `email`, `phone`, `linkedin`, `domain`, `resume` path, `defaultLang`.

## Responsive contract

Breakpoints are the design's: 1080 (burger nav), 1040 (drop decorative
rings/wedges), 760 (stack timeline/chapters/résumé grids), 560 (hide dial chips
+ nav badge, tighter floating-nav inset).

Nav: sticky. `data-floating` (scrollY > 80) insets it into a pill with a red
bottom rule; `data-hidden` (scrolling down past 240px) tucks it away, scrolling
up brings it back. Both set by `updateNav()` in app.js; never while the mobile
menu is open or under reduced motion.
Additions beyond the design are commented `(+)` in `styles.css`. Print styles
cover the résumé route only (`@media print`).

Box model is **content-box** on purpose (the design relies on it). Do not add a
global `* { box-sizing: border-box }`; set it per element where the design does.

## Conventions

- Colors/type only through tokens in `:root`. Hex values appear once, in `:root`.
- Hover effects are CSS `:hover`; only the hero dial needs JS (`turnDial`).
- Templates escape all data through `esc()`. No HTML inside `data.js` strings.
- `[data-reveal]` elements fade in via IntersectionObserver; `[data-stagger]`
  children get 55 ms incremental delays; `[data-count]` numbers count up.
- `[data-stripe]` backgrounds are phase-aligned to the page by `alignStripes()`
  so adjacent stripe blocks look like one pattern. Period = 11·√2 px.
- Analytics: GA4 `G-C14TK36RXS` carried over from the previous site.

## Verify a change

1. `python3 -m http.server 8000` in this folder, open `http://localhost:8000/`.
2. Check 320, 390, 768, 1024, 1440 px widths. Nothing may scroll horizontally.
3. Walk every route in the table above, plus a bogus hash for the 404.
4. On `#resume`, run Print preview: one column, no nav/footer, white background.
5. Toggle "reduce motion" in the OS: reveals must be instant, no animations.
   That OS setting is the only motion switch; there is no config flag.
6. `node js/copy.check.js` passes. Switch EN↔ES on a case study: same hash,
   translated copy, choice survives a reload; clear `ec-lang` in localStorage
   and reload with a Spanish-first browser to see auto-detection.
